# 📊 Colabs Project: Premium Interactive Data Dashboard

A high-performance, vibrant, and interactive web application built with **Streamlit** and **Plotly** to visualize sales records and membership analytics dynamically. 

Developed by **Eshaal Atif** as part of a data automation and analytics portfolio.

---

## ✨ Features
* **Premium UI/UX:** Styled with custom dark-mode CSS aesthetics and dynamic gradients.
* **Interactive Data Visualization:** Implements a smooth, reactive **Plotly Donut Chart** with hover-highlighting and real-time data inspection.
* **Vibrant Color Themes:** Interactive sidebar dropdown that allows users to switch between themes (*Neon Punch*, *Electric Cyber*, *Sunset Glow*) on the fly.
* **Live KPI Metrics:** Displays key indicators like *Total Revenue* and *Total Bookings* using dynamically calculated backend logic.
* **Data Transparency:** Features an expandable layout to inspect raw underlying Pandas DataFrames (`bookings_data` and `members_data`).

---

## 🛠️ Tech Stack & Libraries
* **Frontend Framework:** Streamlit (Python-based Web UI)
* **Data Manipulation:** Pandas
* **Data Visualization:** Plotly Express
* **Styling:** Custom CSS Integration
